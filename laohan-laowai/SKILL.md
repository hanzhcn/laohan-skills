# laohan-laowai — 老外博主复刻数字人全流程

## 使命与合同

**用选定形象、专属音色与教育/文化内容制作数字人口播**。本skill是七阶段总控，本机/服务器CLI自动化，不走网页向导；确需基础素材时才按项目授权调用产品API。首个Deborah/海思博士案例是历史实例，当前形象/稿件/接受状态以各项目STATUS为准；用户当前指令和项目合同优先于本skill。

## 七阶段流程

**先分流再执行**：按稳定的博主/形象身份查项目声音资产登记。同一博主后续视频默认复用同一个已选模型版本；换集数、稿件、服装、场景或参考风格不等于新博主，也不触发重新训练。已有形象素材先核本期适用性，不强制重下载整套训练素材。新博主缺模型才从①/②首建；有备份但运行目录缺失时恢复组装，不重新训练。详细分流与依赖核对见 yinse 第0步。

### ① 博主选型与资料包

- 选型标准：教育者可信度 > 第一视角口播形态（talking head，非 vlog/skit/旁白）> 数据 > 类型差异
- 下载 5-8 条视频（laohan-xiazai：TikTok 用 yt-dlp 直下）+ info.json 元数据
- **口播形态逐帧验证**（抽帧+视觉模型确认正脸对镜头说话；抽帧落在无字幕间隙≠干净，必须多点验证）
- 选定博主不等于肖像/音色使用权、学历与亲历陈述已核实；不能以“改用虚构姓名”或“尚未商业化”宣称这些问题已解决。按项目合同核身份/来源/使用范围，不冒用真人身份、履历或接受记录。
- 换/加博主同步当前项目的素材追踪清单；素材数量与历史流量只作取样依据，实际可用性需本期核验。

### ② 声音资产（已验模型为前置，默认复用）

**调用 skill `laohan-yinse` 第0步**：先核本博主既有模型版本、权重SHA、底模/配置、参考音频及逐字文本、原验收证据。可用则直达第7步生成本期配音；需恢复则只恢复同一模型。确无已建模型才按8–10分钟净语料→服务器微调→回迁/登记/验收首建。重新训练或切换默认模型须有具名原因与负责人明确决定，新版本另存，不覆盖已选版和回滚资产。

### ③ 形象素材处理

- **分清入口限制**：竖版/短边≥720/时长≥8秒/≤30fps/MP4/<200MB是历史产品资产上传要求，不能当当前same-voice CLI的通用硬门；确需产品上传先读该产品现行合同。same-voice按当前工具核输入与几何，prepare转25fps并保持源画幅；原生清晰度、正脸/嘴部可见、字幕/遮挡与连续画面由本期视觉检查裁决，不靠升采样冒称细节达标。
- **不把产品上传门当same-voice适配验收**：576宽可通过本机prepare不证明TBDub实际效果；720宽也不证明全程无字/无遮挡。连续检查并先做已授权小样，不能拿几张无字截图保证整段干净。
- **字幕必须去除**（会被引擎复制进成片）：博主视频普遍带字幕 → 底部 crop 或换无字幕条；多点抽帧验证（首/中/尾/多段）
- 转码H.264、保存clean素材和剪辑边界/SHA；项目方法入口按项目INDEX读取，不恢复旧`docs/dh-production-guide.md`根路径。

### ④ 形象与声音资产（复用已有素材，不走产品注册）

- **形象素材：已有博主视频直接复用**（prepare 前多点抽帧验证全程同一正脸；开头 B-roll 插入画面必须掐掉——见⑤坑）
- **声音：laohan-yinse 微调模型整稿合成**（见②调用，24kHz PCM16 WAV 由 yinse 第 7 步产出）
- ~~产品 avatar-assets/voice-assets API 注册~~ **已淘汰**（2026-10-28）：那是产品网页向导链（零样本参考录音+29积分/次渲染），与本 skill 的 same-voice 路线互斥，且违反"声音不走零样本"红线。历史踩坑记录（MIME 显式 type / consentVersion=voice-reference-v2 / loudnorm 电平门禁）仅当未来确需产品链时参考。

### ⑤ 同声口型渲染（DH-ROUTE 路线④，2026-10-28 实战验证——唯一正确流程）

**方法真源：`~/Documents/laohanvideo/motion/mastery/DH-ROUTE.md` + `motion/tools/README-same-voice.md`（本节只是入口索引，冲突以真源为准）。**

DH-ROUTE是Jeffrey/Motion项目的方法；本项目借用同声工具、时钟与资源保护，不继承其v3-05、历史首单验收/发布、Motion接入状态或提前候选授权。当前博主用自己的已验模型，本期输入/接受/发布仍看本项目合同与STATUS。以下`motion/...`命令从`~/Documents/laohanvideo`根执行，本项目音频/形象/输出均用真实绝对路径，不在当前内容项目臆造motion目录。

不走的路（都验证过不是正路）：产品 lease/operations 报价链（29积分/次，网页向导已淘汰）、ispeech 图+音频（另一条产品链）、直控生产 worker。

```
① 最终 WAV：音色模型在 pro6000-a 合成整稿（laohan-yinse 流程）→ 24kHz 单声道 PCM16
② 形象素材：已有素材直接复用（无需产品订单）
③ Mac prepare：python3 motion/tools/same-voice-local.py prepare \
     --audio <24k.wav绝对路径> --avatar <形象.mp4绝对路径> --max-input-frames <本期已核上限> --out <全新目录绝对路径>
④ validate manifest → 上传 manifest/inputs/chunks/run-same-voice-remote.py 到
   pro6000-a:/root/autodl-tmp/laohan/motion-same-voice/<小写实验名>/
⑤ 预检（无 --run）→ 真跑：--run（total_timeout 3600s，单块 480s 上限）
⑥ Mac assemble：same-voice-local.py assemble → same-voice-candidate.mp4（原 WAV 主声）
```

**坑（全部实战踩过）**：
- ★形象素材开头可能是插入 B-roll（案例画面）——prepare 前多点抽帧验证全程同一正脸；mediapipe 丢脸 >10 帧直接 RuntimeError（chunk-001 判例：开头 5 秒小女孩 B-roll）
- ★生产活动保护触发即保存STOP现场。仅旧执行者及子进程组退出、检查点SHA/原基线/原范围/原截止均满足时，才按README显式恢复一次；生产基线改变不能用resume重置，更不能换目录无限重试同一失败块。
- 音频必须24k单声道PCM16；分块上限在11—300内按本期几何/算力已核条件选择并记录。180仅是pro6000-a/1080×1920的历史参考，不保证其他几何内存安全；不提高20GiB等冻结阈值、不改已运行manifest绕过恢复约束
- 冻结SHA对象是安全模块`/root/autodl-tmp/laohan/motion-method-v2-20261019/run-isolated-pilot.py`，须等于`469d820e11e5b89820a2c3874c08553ed83dfb8cb18952bbc20dd83b4b471487`。本次上传的`run-same-voice-remote.py`另记实际SHA，不能拿469d当其文件SHA或编造校验参数
- 完成证据：assemble产物全帧数与清单相符，ffmpeg完整解码无错误（ffprobe只核元数据/帧数）；状态为候选待连续复看与Jeffrey接受。

### ⑤.5 成片统一加速（老方法既有项，2026-10-28 补录——别漏）

倍率按本期确认；未选档不自动套1.05/1.10。先查Motion交付链或其他上游是否已应用speed，记录来源与累计倍率，只在一个明确阶段应用一次。下面仅用于音画已对齐且同起点的输入，不用各自归零掩盖原有偏移；它是派生示例，不是免测的同步保证：
```bash
ffmpeg -n -i <成片>.mp4 -filter_complex "[0:v]settb=AVTB,setpts=(PTS-STARTPTS)/<S>[v];[0:a]asetpts=PTS-STARTPTS,atempo=<S>[a]" -map "[v]" -map "[a]" -fps_mode vfr -enc_time_base:v filter -c:v libx264 -crf 22 -c:a aac -b:a 128k <加速版>.mp4
# S 常用 1.05（微紧凑）/1.10（抖音节奏），音高不变；首期 Jeffrey 选档后每期固定
# 输出帧率策略还须满足本期交付合同；需要CFR时另核帧取整与首尾偏移，不把vfr当平台通用要求
# 单独atempo声音而不调整画面会破坏原唇音时钟，不用来冒充同因子派生
```

加速版是新派生：记录倍率、输入与输出SHA、A/V起点与时长；外置字幕/词锚先按倍率换算，再对派生实际音频复核，不能只凭理论除倍率。已烧录字幕随画面变速，不再重复施加倍率；若实听词锚错位则重制字幕。`atempo`也可能改变局部边界，重跑受影响的听感、首末词、唇音/累计偏移、接缝和机械门，通过后才可复用原推理结果；不过则保留原速或另做有证据的修正，不以同因子免验。原WAV作为来源保留，不宣称加速后音轨与其逐样本一致，不直接沿用旧SRT。

### ⑥ 后期

- 字幕：**中文大在上、英文小在下**（同屏成对；英文口播，中文主读、英文辅读）
- 字幕先看本期实际画面再排：按语义切短句；字体/颜色/底条是本期设计选择，未获接受的样式不得写成通用“美观公式”。只改字幕时，用本期已核无字幕底片本机另存新候选，直接复用原音轨及口型时钟；保留旧片、原音轨、模型与回滚资产，不重复训练/口型、不进入模型清理。
- 有用户视觉参考时，先拆字形/字重、中英字号比例、颜色对比、成组行距、意群切换与画面留白，再放到本期相同画面比较；不照搬参考的低字幕位置、翻译错误或不适合本场景的配色。动态效果须实际看时间序列，抽帧不足时明确未知。安全与可读通过不代表美观已接受，最终看实际样片与用户反馈。
- 短双语标题是主题提示，逐句字幕对应口播：按开场能否立即交代主题及本片留白决定是否需要，试排时核标题/字幕/脸手之间的主次与拥挤。标题与正文内容一致，不添加未经核实的身份、履历或事实；不替换真实口播字幕。出现时长按本片节奏试排，不默认常驻、另加片头或延长全片；没有合适位置或抢阅读时缩短、简化或取消。
- **抖音遮挡检查**：整块字幕须避开底部标题/文案/账号/导航与右侧互动栏，并避开人物嘴部；按字形、描边、阴影及底条/背景框（如有）的完整视觉边界检查。同屏中英之间也检查实际字形间距，只测合并外框不能证明内部不叠字。分别实看中文/英文最长实际条目、各自多行条（如有）及不同背景，不能只核MarginV或首帧；没有多行记不适用，不为检查强造两行，三行过密/相撞/超界时先重分句再测。优先核当前平台/剪辑器的实际预览；只能用自定遮挡模拟时，标明模拟尺寸与假设，不能把经验像素说成官方通用安全区或保证所有机型不挡。字幕样片仍交Jeffrey接受。
- BGM按本期要求选择并避让人声；违规检测绑定当前稿与当前版本，不复用其他批次CLEAR。
- AI平台声明与片内水印分别按当前项目合同、Jeffrey最新明确指令及适用平台要求核对；不因skill的历史例子自行改开关或宣称覆盖所有项目合规条款。包装/字幕仅在本期要求范围内执行。

## 故障诊断顺序（源自声音方法 §4，补录）

- 口型跟不上/错位 → **先查音轨再重合成**：①核成片音轨=本次 WAV（时长/身份）②查时间轴 PTS 偏移（管线侧问题）③确属语速问题才回重合成（换沉稳参考+重过听感门）
- 音色不像 → 核风格路由 → 换相邻风格对比 → 仍不像报 Jeffrey（触发重训评估）

- **凭据零入档**：lease/token 只存在于运行时内存与既定凭证文件，不写进 skill/项目档案/git

## 失败路径

- 声音模型未建成 → 全流程停在②，不跳过训练直接渲染（零样本已被禁用）
- 形象素材字幕去不净/硬门槛不达 → 换素材条或重新选型，不降门槛上传
- 渲染链失败 → 按DH-ROUTE/README保留失败现场、原预算和检查点，执行其有限恢复条件；不得新增“再试三次”、换目录清零失败次数或退回网页/产品链绕路。
- 验收不过按原因回退：画质/遮挡等视觉问题回本期素材候选；音色/自然度回yinse核数据、模型和参考；口型问题先核音轨身份、PTS和接缝再决定重算。保留原STOP/预算/检查点，不一律换人、不硬发

## 清理临时产物，保护长期声音资产

## 服务器协作判例（2026-10-28 实战，pro6000-a）

- **网络/worker故障**须由具名生产维护任务处置；内容制作不得据历史判例重启worker或结束其它工作线进程。只读核实并让路，只能回收本任务已核身份的离线进程组。
- **resume基线变化**是保护条件，不能当成“脏了就换目录绕过”。保留原STOP/基线/次数；生产空闲且旧执行者已退后，确需继续时由root按README显式登记尚未计算范围的新有限阶段，不伪造旧阶段成功。
- `--expected-checkpoint-sha256`是batch-state.json文件本身SHA；内存增量或生产活动保护触发时不提高阈值、不盲重试、不清全局缓存。
- 该SHA在服务器只读运行`sha256sum <本次实验绝对目录>/outputs/batch-state.json`取得；不是模型权重的checkpoint SHA，也不是manifest SHA。保留原STOP文件不改字节，runner会再次核同一文件与真实成功回执
- **分块断点**：从真实batch-state读成功范围。仅已成功0—16块、未算第17块时，零基左闭右开`--start-chunk 17 --end-chunk 18`才表示18块中的最后一块；它不另授恢复/续时权限。按README核原预算/范围/恢复或显式新有限阶段条件；assemble用`--additional-outputs`合并，消费旧STOP的成功前缀还必须显式`--include-verified-stopped-prefix`，逐块核成功退出回执/SHA/几何/帧数，失败块不接纳

## kb78769 全链实战判例（2026-10-29 首期出片）

> 本次环境的排障记录，不是跨输入/机器的最优参数或耗时保证。同一博主下期优先复用已建资产，不重跑首建流程；不得承诺素材30分钟、训练70分钟、字幕20分钟或口型必定一次成功。

### 素材判定（Qwen听感不可信，用信号法）
- **Qwen2.5-Omni-3B 的 music/reverb 判断不可用**（校准集实测：加明显合成音乐报"no music"、自然声全报 echo uncertain）——语言模型听感≠声学仪器，只当第三路 ASR 参考
- **BGM 判定信号法三步**（numpy+soundfile 即可，判据透明）：①源级停顿残留（帧RMS低于floor*1.5且speech-20dB 的帧）②最深停顿 dBFS 接近干净底噪(-49~-60)=否定恒定BGM；③响停顿(>-38dBFS且≥0.3s)总数<1s=否定间歇BGM。残留高但无节拍=高增益词隙尾音，不是音乐
- 转写终稿=Whisper基准+双ASR词级diff+语境裁决（SenseVoice 分词伪影 navaro/fuckinguck 系统性不采；W 把 spaces 听成 's faces 这类靠 S+Q 2:1 纠）
- 孤立环境声(0.3-0.4s)直接弃段不微裁——总量够时弃用优于精修

### 训练（pro6000-a）
- 入口必须 `launch_voice.py pipeline --run --timeout 3600`（直接 pipeline --run 会被 STOP）；远端 python 用绝对路径 `/root/autodl-tmp/cosyvoice-train/venv/bin/python`（非交互 PATH 无 python3）
