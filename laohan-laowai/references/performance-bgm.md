# 表现力与BGM：从对标到下一集

适用：用户给参考视频，或指出讲得平、节奏散、音乐/视觉弱。输入为完整参考片、本期定稿、同一形象素材、已选模型/参考、干声与raw（已存在时）。单改后期不启动训练或GPU；换形象/人设/发布仍按本项目授权。

## 先识别差距

完整取片并记作品ID、来源、时长与SHA。按时间线对照开头、论点转折、结尾，记录可见表情/手势、文本、镜头、字幕、声音各自证据。抽帧/视觉模型不能听语气或BGM；ASR不能判音乐质感，响度不能证明好听。只能收到抽帧时明示范围，模型给错的时间点回原帧/原音频裁决。获取失败查当前下载skill，不为拿一条片重启共享浏览器或全量更新工具。

把差距归到实际来源：素材已有表情/动作，配音有重音/停顿/情绪，文案有冲突/兑现，后期有构图/字幕/音乐。嘴型算通不会自动增加表演；音乐也补不了空泛文案。不要从成片推定对方用了哪种TTS、口型引擎或参数。

## GPU前：内容、人物和语气一起确定

1. 本期只承诺一个清楚收获。开头尽早进入家长熟悉的冲突/场景；有真实依据再用具体数字、对照和反转。背景身份只在必要且已核实时出现，避免先自我介绍一长段才到主题。不强设所有视频50秒或固定句数。
2. 在稿件旁写情绪/节奏说明，例如“提出矛盾→具体对照→停顿→给行动”，说明不进`spoken.txt`。选同一形象中适合该情绪的已有素材；核全段嘴/眼神/手势、循环、标题留白。素材不合适优先换同一形象条目或试构图，不自动换人/人设。
3. 用已选模型和既有已校准参考。首次新风格才做代表性短句比较；优先复用既有WAV片段。对紧凑/有力的要求先改冗余文字与停顿，不默认全片加速、重训或塞未经验证的情绪标签。最终仍核本期整轨WAV。
4. 将已选常驻标题、逐句双语字幕、同一段声音和候选BGM放进一个12–20秒小样；不每种元素各开一轮。GPU前可用源画面试构图/语气，清楚标记尚非新口型；有可用raw直接后期。短样不替代完整成片审片。

## 口型后：干声和交付混音分开

```
已验干声WAV ─→ ASR词锚 / prepare→口型→raw
                                       └→ 标题+字幕+获准BGM→交付混音候选
```

- 音乐服务于本期情绪，可用无歌词、节奏克制的候选作起点；不强迫每段换曲/加音效。先核来源、可用范围与必要署名。抖音站内音乐不能自动授权下载后跨平台用；对标抽取的混合音轨仅供分析，不把别人的人声一并混进本片。
- 先测人声/候选混音的整体响度与真峰值，再调增益/必要控峰；平均低但峰值已高时，不能直接整体加大。不把固定LUFS、增益百分比或LRA数值当全项目硬门。
- 先让人声清楚，音乐在人声时压低（可用sidechaincompress），停顿适度回升；重音、尾字和呼吸不能被盖。音乐首尾淡入淡出，结尾不多拖一段；检查压低回升是否抽动、循环是否突兀。需要连续试听，未实听明确待验。
- 音乐处理只作用音乐支路；主轨可按本期测量做不改变时序的增益/控峰。禁止通过`amix`默认自动归一让人声整体偷偷变小；显式`normalize=0`后留峰值余量并测最终输出。
- 保留干声原文件/SHA/采样数、raw身份/时钟、音乐来源/SHA/片段、滤镜、最终混音与成片SHA。混音AAC是新派生，不能要求它和干声逐样本一致；核的是人声来源、时间不漂、首末词/字幕/嘴型仍对应。仅换BGM不因AAC变化重算口型/词锚。

## 已实跑的本机18秒混音示例

下面验证的是后期滤镜和时钟。输入须为**已经音画对齐且同起点**的18秒样段，BGM至少18秒，另存输出；不用于把错位输入各自归零。示例值只是试听起点，不是已接受风格/通用响度目标。正式全片把时长和淡出位置改为本期实际值；从raw同一次烧ASS与混音，避免反复重编码。仅改音乐时可直接复制视频流。

```bash
(
set -e
FFMPEG=/opt/homebrew/opt/ffmpeg@7/bin/ffmpeg
# CLIP_FILE=已对齐的18秒干声样段，BGM_FILE=来源可核且至少18秒的音乐
# OUTPUT_FILE=全新MP4
: "${CLIP_FILE:?缺样段}" "${BGM_FILE:?缺音乐}" "${OUTPUT_FILE:?缺新输出}"
if [ -e "$OUTPUT_FILE" ]; then echo '输出已存在，请另存新候选' >&2; exit 1; fi
"$FFMPEG" -nostdin -n -i "$CLIP_FILE" -i "$BGM_FILE" \
  -filter_complex "[0:a]asplit=2[voice][key];[1:a]atrim=duration=18,asetpts=PTS-STARTPTS,volume=0.10,afade=t=in:d=0.8,afade=t=out:st=16.8:d=1.2[music];[music][key]sidechaincompress=threshold=0.03:ratio=5:attack=30:release=350[duck];[voice][duck]amix=inputs=2:normalize=0:duration=first,loudnorm=I=-18:TP=-1.5:LRA=9:print_format=json[mix]" \
  -map 0:v:0 -map "[mix]" -c:v copy -c:a aac -b:a 192k -ar 48000 \
  -t 18 -movflags +faststart "$OUTPUT_FILE"
)
```

用ffprobe核实际流、起点/片长/帧数，并以ffmpeg完整解码；再实测**输出**响度/真峰值，不能拿loudnorm的请求值当实测值。保留同片段无音乐对照并匹配两版的实测整体响度，方便辨别改善来自音乐还是音量；它们是短样，不默认出两版全片。若只做机械验证，登记为机械通过/听感待验。

滤镜语义依据[FFmpeg官方文档](https://ffmpeg.org/ffmpeg-filters.html)：sidechaincompress用第二路作为压缩检测信号；amix显式关闭自动归一；loudnorm之后显式指定输出采样率。使用现有ffmpeg前先核实际滤镜可用。

显式输出存在检查与`-n`同时保留：本机ffmpeg@7实测已有输出时虽不覆盖，却可能返回0，不能只凭退出码登记新候选成功。子shell让缺参/已有输出失败不会退出用户的交互shell；生成后仍须核真实媒体与身份。
