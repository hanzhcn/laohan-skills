# 每集按改动执行

先读项目STATUS/INDEX、当前稿件、声音资产登记与已选标题/速度。这里只组织现有入口，不增加编排器、常驻服务或新的通过凭证；实际命令分别取项目声音README和same-voice README。

## 改动与必做范围

| 本期变化 | 应执行 | 不重复执行 |
|---|---|---|
| 同一博主、已选模型/参考、全新稿件 | fresh核资产/依赖/运行身份及预算；本期稿件事实与违规；`launch_voice.py synth`默认检查后受控合成；完整新WAV音文/听感；适用形象prepare/validate/口型/assemble；后期与成片检查 | 训练语料重清洗、特征/parquet、训练、权重剥离、模型首建A/B/10次稳定性、参考池重建 |
| 只改字幕/标题样式或位置，原音轨/口型/速度不变 | 从已核无字幕raw试排；核所有实际字形/内部间距/UI和脸嘴、标题所选时长及词锚；一次烧录并copy音轨；解码/时钟/音轨核对及实际样片 | TTS、ASR重跑、模型/口型重算、速度多版；词锚仅在原输入/文本/时间轴及工具依赖证据可核时复用 |
| 英文口播改字、换参考、重合成或音频剪切 | 重新核受影响文本/参考、生成新WAV，整轨检查并重算受影响口型/词锚；保留原片可回退 | 未变模型训练；不以“时长相同”复用旧口型 |
| 只换形象素材 | 连续核新素材/顶部留白、clean几何；prepare/validate/小样及口型/组装/视觉 | 原WAV确实未变且身份/依赖可核时不重合成或重ASR；仍核新成片音轨与同步 |
| 迁机或运行包丢失 | 恢复同版模型/参考/依赖，fresh核SHA与环境，实际加载短句试合成 | 自动重训、自动升级模型或换零样本 |
| 新博主/明确批准重训、方法或脚本变化 | 训练或变更涉及的前置/真实入口正反例及独立复核 | 不裁剪生产、声音资产保护、音文/听感和发布权限门 |

多项变化取必做范围并集；不确定影响就查证或执行相应检查。复用须保留旧候选/时间/环境/结果，并核关联源码、传递依赖、测试集、配置/协议和环境未变或兼容；单一hash、旧失败/未测记录不构成通过。不改旧回执的候选身份。

## 缩短等待与返工

1. GPU前核定稿、纯英文spoken、整轨听感、素材连续适用/顶部留白、工具/磁盘/资源和既有生产保护；输入不合格先改，不用全片GPU排障。
2. 同一WAV只做一次有绑定的词级ASR，兼顾音文差异和字幕词锚；有疑点才加独立识别或审音。ASR不能替代真实听感，训练数据校对规则不因每集复用而削弱。
3. 已接受的新WAV开始口型计算后，可在本机并行做字幕翻译/词锚与标题小样；不同时叠加共享GPU上的训练/TTS/口型。小样定风格后只从raw完整烧录一次，默认只产已定原速/倍率的一版。改稿或时钟变化时，小样与词锚重核。
4. 使用已核几何的分块起点；120帧只是kb78769本期参考。沿remote脚本保留每块身份、离线环境、cache建议、原预算及有限恢复；不提高内存门、不制造内存压力、不清全局cache、不换namespace重试失败块。不得用提速名义弱化生产让路。
5. 帧数/时钟/全片解码/响度先机械检查；一次实际连续有声审片覆盖口型、接缝、节奏和字幕/标题，布局仍核最长条/极值。静帧、抽帧AI和文字审查各有能力范围，不能叠加数量冒充全片视听。

## 复核合批

未变的已验工具链不每集重新做代码/方法模型审查。有方法/代码变更时先集中修已知问题、自审和必要正反例，再对同一冻结候选做一次合批异模型对抗复核；按全局满配与独立性规则调用，不为提速降思考、截材料或冒签。只在真实阻断修复、范围/风险变化或未解决疑点时追加受影响差异复核；低风险证据补录不机械重审未变实现。全局或项目强制的额外模型条件仍执行。

每集当前稿件事实/违规、新WAV音文与听感、生产资源/停止保护、最终成片视听和发布批准继续执行。成片接受由Jeffrey按原授权决定；外发需实际指令。平台真实预览与模拟分开，不把候选交付写成发布或手机接受。
