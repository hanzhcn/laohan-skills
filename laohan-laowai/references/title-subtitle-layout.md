# 常驻主题标题与逐句双语字幕

## 来源与适用范围

2026-10-29核读：[字流《口播视频：从选题到发出去》](https://ziliu.online/docs/talking-head)的“上传，开始精剪”和“看一遍，哪里不对改哪里”。教程把开场提示、顶部主题文字与字幕作为可分别编辑的元素。本方法借鉴这种分工与分轨，不引入字流产品、其默认语速/配乐/发布设置，也不把宣传数字或平台效果当已核事实。

“成长”系列下期采用顶部常驻双语主题标题＋下方逐句双语字幕，来自Jeffrey本次决定；不是该教程规定，也不是抖音统一要求。其他项目先读自己的方法与本期决定。已制作EP01 v4.1的胸前3秒标题保留，不因本方法自动返工。

## 执行顺序

1. **准备输入**：本期已核稿件、简短中英主题标题、无字幕底片、逐句双语文本/词锚、画幅与A/V时钟。标题概括整条内容；若视频先讲年龄责任、再讲报酬，不能只用后半段小问题代表全片。标题中文主读、英文稍小，彼此表达一致，不添加新履历/事实。
2. **选素材时预留标题区**：在prepare/口型前，查看同一形象整段头部与手势的活动范围；顶部须容得下完整双语标题及描边/阴影，并避开平台顶部界面。无留白先换合适素材；仅能改构图解决时先做布局小样再定，核原生清晰度与嘴部，不硬压额头、不默默缩字。达不到则记录原因按本期决定调整形式，不能自动回退成3秒或取消标题。
3. **分轨与排版**：主题标题在上方留白，位置稳定、字号克制；对白字幕在下方，中文大在上、英文稍小在下，按意群切换。标题不跟每句对白改写；不默认另外叠一套双语开场大字。位置/字号/配色按本片调整，不把下方示例坐标当通用安全区。
4. **绑定时轴**：常驻标题中/英两条事件使用同一开始和结束时间，覆盖本期整片，字幕各用自己的词锚。0起点示例为0到实际片长D，End向上取到厘秒覆盖最后一帧；D来自本期底片，不沿用示例6秒或旧片84.12秒。已有变速先查累计倍率，沿用本期实际派生时钟；不为做标题新增加速，不各自归零掩盖音画偏移。
5. **本机渲染**：复制[6秒ASS布局样例](title-subtitle-example.ass)到本期后期目录，替换主题/逐句文本/词锚、PlayRes、实际字形布局及全片End。样例不默认带AI轨；项目/用户明确禁止片内AI标识时，核模板、raw和最终片均无AI文字/角标/水印，不从历史样例继承。然后用本期已核raw一次烧标题和字幕；不改音频时直接复制原音轨，需要BGM时按[混音方法](performance-bgm.md)同次输出新混音并分别登记干声/混音身份，另存新候选。已烧字幕的成片不再叠烧；仅后期变动不重训、不重新算口型、不清理模型。
6. **实际看片后交付**：先在本片首/中/尾、头部/手势极值和中英最长字幕上检查整组布局，确认中后段与结尾仍有标题。看字形、描边、阴影及标题/两种字幕之间的实际间距、背景对比；另核全画面/四边是否出现本期禁止的标识。连续播放另核切换与主次，不能拿静帧代替。优先真实平台预览；自定遮挡模拟须注明假设。全片另核时长/帧数/音轨一致与完整解码，记录ASS/底片/成片身份。技术可交看片不等于Jeffrey美观接受或获准发布。

## 成长系列固定起点（2026-10-30）

Jeffrey反馈原版汉字偏小并要求固定。720×1280、当前PingFang SC/Arial与libass入口采用：中文对白52、英文对白29、中文标题72、英文标题34；1080×1920按1.5倍等比，不能将这些ASS数值原样输入其他软件。标题常驻全片。位置仍按本期头部活动与完整视觉边界试排，不把字号合格等同布局合格。

选择依据：[CapCut官方字幕指南](https://www.capcut.com/resource/caption-style)要求手机可读、保留主体与界面空间；[官方字号说明](https://www.capcut.com/help/font-units-in-capcut)说明软件字号不是通用像素，建议导出实测；[TikTok官方](https://ads.tiktok.com/resources/help/article/tiktok-auction-in-feed-ads?lang=en)说明安全区随画幅、文案和附加组件变化。这些资料没有给本项目统一数字，上述数值是本项目实测起点，不称官方推荐字号或抖音实机保证。[libass开发者说明](https://github.com/libass/libass/issues/644)也表明ASS字号与CSS em不同；不得用“全角字步进必等于字号”否定真实渲染。

生成cue前按完整意群切分：中文>14个非空白字符预拆；数字与单位、姓名与年龄不拆断；不留孤立的“的/房租”等尾巴；中文对应同窗英文的意思。中英从同一个起止窗口生成，start≥上一end，禁止事后只推一层。英文两行在单词边界换行，涉及姓名、数字或短语时人工核查。整句过宽先重拆，不把汉字缩回小字。

验收仍跑全部cue字形/内部叠字/最长和多行条，再看含四角的全幅五点以及360×640手机尺寸预览。绑定ASS SHA到生成计划、字形报告与渲染输入，过期报告必须拒绝。字号或断句改动只重做后期和受影响检查，不重算口型。当前样式仍交Jeffrey看片，不预签美观接受。

## 本机已有渲染入口

从本期项目目录执行，先把三个变量设为本期真实绝对路径。滤镜示例要求ASS路径不含冒号、单引号或反斜杠；有这些字符先在本期后期目录另存安全文件名，不拼接不可信滤镜表达式。FFmpeg须实际有ass/libass能力；本机当前入口为：

```bash
FFMPEG=/opt/homebrew/opt/ffmpeg@7/bin/ffmpeg
# RAW_FILE=本期已核无字幕底片绝对路径
# ASS_FILE=本期已改好全部文本/时轴/画幅/位置的ASS绝对路径
# OUTPUT_FILE=全新候选MP4绝对路径
: "${RAW_FILE:?先设置本期raw路径}" "${ASS_FILE:?先设置本期ASS路径}" "${OUTPUT_FILE:?先设置全新输出路径}"
"$FFMPEG" -nostdin -n -i "$RAW_FILE" -vf "ass=$ASS_FILE" \
  -map 0:v:0 -map 0:a:0 -fps_mode passthrough \
  -c:v libx264 -preset fast -crf 20 -threads 4 -c:a copy \
  -movflags +faststart "$OUTPUT_FILE"
```

保留原raw、ASS与旧候选。示例验证只证明本机ASS入口与全程事件，不能证明下一条真人素材/平台界面/审美已通过。

上面`-c:a copy`只适用于音轨未改的字幕分支；有BGM则使用混音分支，不能宣称最终AAC仍与干声逐样本一致。
