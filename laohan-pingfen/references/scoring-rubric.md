### 合成与档位

- 总分 = Σ(维度分/5 × 权重) × 100，保留 1 位小数。
- 档位：S ≥80 / A 65-79 / B 50-64 / C 35-49 / D <35。
- 预测播放锚（账号基线 median 的倍数，随 baseline.json 重算刷新）：S→≥3× / A→1.5-3× / B→0.8-1.5× / C/D→<0.8×。

## 实际分（ACTUAL）— 真实数据 vs 账号分位

主判窗口：48h 精确点（迟到点标注 +Δh）；终判 7d；13h 内读数无判定效力。

| 指标 | 权重 | 说明 |
|------|------|------|
| 播放量（窗口口径） | 0.45 | 主指标，相对账号历史分布分位 |
| 千播转发密度 | 0.25 | 裂变证据（双门第二门的直接读数） |
| 千播评论密度 | 0.15 | 互动设计效果（报数式问题的验证） |
| 2s 跳出率（反向） | 0.10 | 入口效率（标题分派+前5秒的读数） |
| 千播（赞+藏+吸粉） | 0.05 | 综合留存 |

- 等级：S = 播放 ≥3×median 或 ≥P90；A = P75+；B = P50-P75；C = P25-P50；D = <P25。
- 结构诊断：入口层（2s跳出）/ 裂变层（千播转）/ 互动层（千播评）三层强弱点标注；"结构性险胜"识别（播放高+完播垫底=转发飞轮覆盖，EP06 模式）与"入口强无裂变"识别（EP03R 模式：跳出最优+播放塌）。
- 完播率为观察指标不进权重（裁决2：分发的结果非原因；EP06 完播 2.33% 全号倒数第一仍 6.1万）。

## 校准规则（CALIBRATE）

- verdict 映射：预测档-实际档差 0=CALIBRATED；预测高 1=OVERESTIMATED(1)，高 ≥2=OVERESTIMATED(2) 强制归因；反向同理 UNDERESTIMATED。
- 归因定位：对失准维度重审——该维高分但对应真实读数（各维→指标映射：T1/T4→2s跳出、F1/F2→千播转、R1/R2→千播评、T2/T3→播放量级）在同分布里垫底即证伪该维打分锚。
- 提案约束：权重步长 ±0.02，单版本最多动 3 维，动后各层权重和不变（层内调配）或明示重配理由。
- 生效门槛：回测（对全历史重打分）区分度不退化——已证 S 级（EP06）必须仍居全历史最高总分，已证塌方（EP03old）必须仍居最低档；区分度指标 = 预测总分与 log(plays) 的 Spearman 秩相关不下降。
- 升级钩子：有效样本（预测+实际齐）≥30 → 评估回归拟合权重（clipforge MIN_SAMPLES=100+R²≥0.1 门禁先例；小样本禁止硬拟合）。

## v1.1 锚修正（2026-11-15，初版回测校准）

回测发现（10 期全历史，v1.0 rho=0.564→v1.1 rho=0.636）：

1. **T1 二手冲突锚**：标题冲突来源为"引自己评论区/别人家讨论"（二手）较"自家场景/自身立场宣示"（一手）扣 1.5 分——新观众对二手冲突无立场可站。判例：EP08「两百条评论吵零花钱」T1 4.5→3，预测 80.5/S→实际 3322/C（OVER-2档触发本锚）。
2. **T3 元数字锚**：证明性数字（评论数/研究对数，如"两百条评论"）不计入可抄数字锚，较可抄数字（月息1块/1美元×年龄）扣 1 分——元数字证明"这视频火过"不构成观众可抄件。
3. **R2 同域续集衰减锚**：同域第 3 期起报数式问题互动预期衰减 1 分——评论双峰未破判例（EP08 0.31→EP09 0.19 评/k 系列新低，对比 EP01/02 的 2.24-3.04）。
4. **环境变量（rubric 不评分，预测 notes 必附）**：承接池基数——系列承接结构的初始曝光受上期播放约束（EP09 rubric 88.7/实际 B 同构风险），预测段必须写"承接风险"备注，7d 判定后校准环境变量权重认知。
