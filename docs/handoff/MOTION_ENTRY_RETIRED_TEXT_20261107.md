# 镜头友好模式（laohan-chuangzuo 可选扩展，v1）

> 定位：只在 Step 4 写稿句式层叠加**倾向性偏好**的可选模式，默认关闭。不覆盖六步法、style.md/风格文件、Step 5 六关、humanizer-zh 与任何既有合同；对既有方法只加不删不改（rules/skills.md「已验证方法不得因审计被压缩」）。

## 为什么有这个模式

下游 MotionGit 模板出片（`motion/adapters/mk-adapter.py`）按语义模式分镜：开场主张→title、术语强调→keyword、真实数值对比→vs、清单要点→checklist、金句→quote、互动收尾→cta。写稿句式靠近这些形态时，「稿件→镜头」的映射接近确定式，自动化出片的语义正确率显著提高（依据：`motion/HANDOFF-WORKFLOW-INTEGRATION.md` §三.2/§三.3，方案经 codex 四审 PASS）。

## 四个句式偏好（倾向性，非硬规则）

1. **短主张**：关键节奏点写成 ≤15 字的独立短句（与 style.md「关键节奏点尽量≤15字」既有默认叠加，不是替换）
2. **成对对比句式**：对比内容写成对仗双实体句——「智谱归智谱，DeepSeek 归 DeepSeek」「与其排队等重置，不如多开一个窗口」
3. **清单句**：并列要点用「第一个/第二个/第三个」引导，每个要点独立成句、要点名前置（「第一个，目录隔离。」优于「目录隔离是第一个要点」）
4. **真实数字带单位**：可量化处写具体数字+单位（「十个模型窗口」「两个字母」），不写「很多/大量/不少」

## 两条结构偏好

- **金句独立成段**：quote_anchor 候选句独立成段（原句不被并入长段），方便下游按段提取
- **术语首现集中**：同一技术术语只在一段首次展开解释，之后用短称；便于 keyword 型镜头取词

## sidecar 契约 camera-friendly/v1

启用时默认额外产出 sidecar（正文照旧，只含口播文字）：

- Episode 模式：`02-创作工作稿/镜头结构.json`
- 独立模式：`output/<basename>.镜头结构.json`（与口播稿同 basename）

```json
{
  "contract": "camera-friendly/v1",
  "script_sha256": "<最终有效口播正文的 SHA256>",
  "paragraphs": [
    {"sha256": "<该段原文 SHA256>", "text": "段落原文全文（逐字）", "role": "opening|point|contrast|list|quote|cta"}
  ]
}
```

- `role` 是**语义提示**（opening 开场主张 / point 单要点 / contrast 对比 / list 清单 / quote 金句 / cta 互动收尾），不是模板控件名，更不是模板参数
- `text` 必须与正文段落**逐字一致**；下游适配器按归一化全文匹配，失配即拒绝整个 sidecar 并报错，不模糊容错（codex 预审 F08：绑定用段落全文/SHA，不用前缀）
- `script_sha256` 绑定最终口播正文；humanizer-zh（Step 5.5）或任何实质改稿后必须重出 sidecar（段落 SHA 会失配）
- sidecar **不含** props、视觉参数、时间码、镜头语言——模板表达归适配器与导演阶段（与 SKILL.md「visual_anchors 只给抽象理解任务」同一边界）
- sidecar 不进正文、不进创作决策.json、不进 validator 校验范围（validator 零改动）

# 热点转译选题法

从实时热点中提炼老韩原创选题的方法论。

核心思路：**热点 = 选题来源（100%），老韩视角 + style.md = 差异化。** "原创"不是从零生造，是在别人都说同一个热点的时候，你说得不一样。

**转译公式：你的真实 AI 经历 + 热点话题 = 你专属的选题。** 观众要的不是 AI 知识，是 **AI 跟我的关系**。

**铁律：标准迁就爆款，不迁就创作者。** 观众不关心你有没有经历过，他们关心的是你说的话像不像真话。

## 转译案例

别人在"报道热点"，老韩在"翻译成我的经历"：

| 热点 | 别人怎么讲 | 老韩怎么转译 |
|------|-----------|------------|
| 35岁男子被AI取代通知（知乎242万热度）| 报道新闻、分析法律赔偿 | "我就是那个用AI取代别人的人"——8个agent帮我做内容，一个顶几个人。讲我用AI做掉了什么岗位 |
| AI大模型中文比英文更费Token（36Kr）| 技术分析 | "我月烧50亿token，告诉你中文到底贵在哪"——老兵视角算账：到底值不值 |
| CTO转身去Anthropic当工程师（36Kr）| 行业新闻 | "老韩在互联网十几年见过几次周期"——不是技术分析，是职业选择分析 |
| 假期出游被AI坑惨了（36Kr）| 罗列翻车案例 | "AI帮我规划过旅行，坑了我多少钱"——真金白银的账 |

**模式：** 转译的关键不是换个说法讲同一件事，是**换成你的身份去讲这件事**。

## 三个必答题

对每个候选热点必须回答，三个都通过才成立：

1. **跟 AI 有关系吗？** → 直接相关最好；间接相关需要找到连接点；完全无关 → 跳过
2. **我有真实经历吗？** → 有最好。没有就从老韩的日常找对应——楼下邻居、朋友公司、花过的钱、踩过的坑。基于老韩人设（产品老兵、token大户、十几年互联网）构造合理感受
3. **路人为什么要在意？** → 观众关心的是：能不能赚钱、会不会失业、省不省钱、好不好用。把技术话题翻译成生活语言

## 角度库

| 角度 | 适用场景 | 老韩的优势 |
|------|---------|-----------|
| 就业焦虑 | AI取代岗位、裁员、职业转型 | 你是用AI替代人工的人 |
| 消费/省钱 | AI工具价格、token费用、性价比 | 月烧大量token的真实用户 |
| 教育/成长 | AI学习、能力提升、认知升级 | 从零自学到搭建系统的亲历者 |
| 职业选择 | 行业趋势、跳槽、创业 | 十几年互联网+AI产品视角 |
| 日常场景 | AI在生活中的应用 | 楼下邻居、朋友公司、日常消费 |
| 反常识打假 | AI谣言、过度宣传、虚假承诺 | 花过真金白银试过工具的人 |

**角度选择优先级：反常识性 > 情绪共鸣 > 场景包装潜力。**

## 两句话标题公式（＜30字）

标题必须是两句话，用逗号、句号或破折号连接：

**第一句（主题句，15-20字）：** 说清楚发生了什么 + 你的立场。

**第二句（情绪句，10-20字）：** 用生活化语言拉情绪、反转、或制造悬念。必须有具体画面/数字/场景。

**好的例子：**
- "35岁被AI取代通知，拒绝降薪被开除，法院判了——但我想说句真话"
- "孩子抱AI聊3小时，真不是AI的错，也许他问人活着有什么意思，你不该吓一跳"

**坏的例子：**
- "也许AI能力等级该是划分人群的时候了" — 抽象概念
- "范式转移""赛道消失" — 念出来不像跟朋友说话

**红线：** 总长＜30字，第二句必须存在，禁止抽象概念，标题念出来必须顺嘴。

## 写稿态度铁律（style.md 未覆盖）

style.md 管语感和技法，这里管态度、立场、情绪：

1. **前15秒必须亮出态度**：不只是信息冲突，要有立场
2. **老韩必须下场表态**：至少1处老韩自己的判断/骂人/质问
3. **身份反差是最大炸弹**：老韩立场跟大众预期冲突时，放大不要缩着说
4. **细节要具体到让人愤怒**：不能只说"他公司也这样"，要"设计部五个人裁到两个，活没少，工资降15%"
5. **结尾不能说教**：换成有攻击性的收刀

## 标题破圈规则
