# 秋芝方向模板词典（V1.12）

这是一份创意选型词典，不是额外生产流程。S1—S29恢复自旧版29模板库；S30—S45根据秋芝2046真实抖音主页可观察到的角色、场景和主物件机制补充。每期最终选择3个不同模板族，每个候选仍只组装一条完整提示词，直接生成带中文标题的成图。

## 先选冲突，再选模板

| 内容冲突 | 优先模板族 | 不宜默认 |
|---|---|---|
| 实测、验证、拆解、真假 | 实验验证 | 宇航、庆典 |
| 新品、重大发布、首次出现 | 发布展示 | 末日、日常 |
| 教程、步骤、怎么做 | 教学操作 | 宏大宇航、纯数据 |
| 自动化、Agent、工作流 | 操控协作 | 财神、竞技 |
| 对比、选择、谁更强 | 对抗选择 | 单一产品展台 |
| 风险、淘汰、骗局、危机 | 调查危机 | 庆典、海岛 |
| 盘点、合集、生态、清单 | 集合信息 | 单一英雄道具 |
| 趋势、行业判断、未来 | 远景寓言 | 普通实验室 |
| 创作、影像、生成内容 | 创作舞台 | 商务展台 |
| 赚钱、职业、生活方式 | 生活角色 | 科技实验 |

## 防重复规则

1. 先按语义匹配筛出5—8个模板，再选择3个不同模板族并按推荐程度排序；不要先选“好看”的角色再硬套选题。
2. 一张图只用`1个基础模板 + 最多1个主物件机制`。主物件必须承担打开、托举、检验、操控或拆解等动作，不能只堆在背景里。
3. S1实验室、S3未来办公、S22太空宇航、S30飞船驾驶舱属于`CONDITIONAL_ONLY`：只有口播明确对应实验、办公控制、探索或操控时才能选，不能当AI选题默认背景。
4. 本期01、02、03不得来自同一模板族。若能看到上一期秋芝候选，优先避免01重复上一期01的模板族；若看不到历史，则在语义同分时优先选择非`CONDITIONAL_ONLY`模板。
5. 不随机抽模板。变化来自口播冲突、动作和主物件，不来自无意义换装。
6. 保持`Exactly one Jeffrey`。涉及对比、人群或协作时，用左右环境、物件或非真人符号表达，不能复制多个Jeffrey。

## 提示词组装

每个秋芝方向候选的最终提示词只需写清：

```text
BASE TEMPLATE: [ID + 模板名]
HERO ACTION: [Jeffrey正在做的一个动作]
HERO OBJECT: [与口播事实直接相关的唯一主物件]
SCENE: [模板空间、色彩、光线]
TITLE: [准确中文标题、断行、位置、黄/白大字和粗黑描边]
IDENTITY: [Jeffrey reference约束]
EXCLUDE: [错字、多余文字、平台UI、水印、二维码、额外人物、无关装饰]
```

不要把模板ID或模板名画进封面。模板只是提示词内部的创意依据。
