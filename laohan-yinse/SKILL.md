# laohan-yinse — 复刻博主声音模型

## 使命与合同

**每个复刻博主一个声音模型，一次建立、所有视频复用。** 声音模型是博主复刻的核心资产：数字人=形象克隆+口型驱动，声音来自 TTS——没有本人音色模型，出来的是"通用音色配这张脸"，瞬间违和。

硬性流程：形象处理/视频生成之前，先完成声音模型建立与登记。

## 素材标准

| 项 | 要求 | 不满足的后果 |
|---|---|---|
| 总量 | ≥8-10 分钟纯人声（多条原视频） | 微调训练素材不足 |
| 质量 | 单人清晰口播、领夹麦/近场；无明显 BGM/混响 | BGM 混入训练=音色污染 |
| 格式 | WAV，44.1kHz 单声道 | 任意视频源格式均可，提取时归一 |
| 同源 | 与形象素材同一博主 | 声音与脸不匹配 |

## 工作流（五步）

### 1. 提取（ffmpeg，逐条）

```bash
ffmpeg -y -i <视频>.mp4 -vn -ac 1 -ar 44100 <博主>-<条目名>.wav
```

### 2. 质检

每条 WAV 用 SenseVoice/whisper 转录抽听：确认纯人声；BGM 重、混响重、多人说话的条目剔除或换条。**质检通过才进下一步。**

### 3. 拼接训练主素材 + 截参考段

```bash
# 拼接（concat 列表）
for f in <博主>-*.wav; do echo "file '$f'"; done > concat.txt
ffmpeg -y -f concat -safe 0 -i concat.txt -c copy <博主>-full-<总秒数>s.wav
# 零样本参考段：挑最清晰一段（通常第一条开头），10-30 秒
ffmpeg -y -i <最清晰条>.wav -ss <起点> -t 25 <博主>-reference-25s.wav
```

### 4. 建立（路径 B 为唯一正式方法，Jeffrey 2026-10-27 钉死）

**路径 B：CosyVoice3 fine-tune（服务器训练，正式流程）**
- 素材：`<博主>-full-483s+.wav`（8-10 分钟）
- 环境：CosyVoice3 源码仓（laohanagent gpu-node `cosyvoice3/CosyVoice/`，含 webui.py）；本机 conda `cosyvoice` 环境无 GPU——**训练在 GPU 服务器跑，训完把 checkpoint 拷回本地/注册进 sidecar 模型库**（Jeffrey 先例：服务器训练→本地使用）
- 具体训练命令以 GPU 服务器侧实际脚本为准，首跑时核实并回填本节
- 质量档位：专属模型（高相似度，长期主用）

**路径 A：产品内零样本克隆（仅应急/临时验证，不作为正式交付）**
- 入口：laohanagent 产品 API `/v1/dh/voice-assets`（3-30 秒参考音频，CosyVoice3 零样本）
- 用 `<博主>-reference-25s.wav`；产出即时音色档案
- 限制：音色相似度有限，仅等待 B 模型训练期间的过渡方案

### 5. 登记与验收

**登记表**（项目内维护，防资产丢失）：博主 / 建模日期 / 路径 A or B / 素材位置 / 模型位置或 ID / 验收状态。

**验收三条**（每个音色建完必过）：
1. 固定测试句（目标语言+中文各一句）生成，与原声主观相似度 ≥8/10（Jeffrey 听审拍板）
2. F0 基频域与原声一致（±20Hz 内）
3. 连续生成 10 次无破音/吞字/音色漂移

## 边界与红线

- 只克隆**已决策复刻**的博主（形象复刻合规决策先行——起号期灰色可接受、商业化前换纯生成，声音同理）
- 不把 A 路径的零样本结果冒充 B 路径质量；验收不过回炉
- 模型文件/账号音色不外传；登记表记录完整可追溯
- 服务器训练涉及费用/算力按项目既有授权，不自动开新付费点
